# 10/28 온라인 설명회 질문지

설명회 Q&A에서 물을 질문이다. 위에 있을수록 답에 따라 설계가 바뀐다. 각 질문 아래에는 왜 묻는지(우리가 확인한 사실)와, 답을 못 받았을 때 어떻게 할지를 적었다. 답을 받으면 바로 아래에 적고, 관련 문서(`docs/pleos/`, `docs/architecture.md`)에 반영한다.

## A. 설계가 바뀌는 질문 (꼭)

### A1. WebView 기반 UI가 앱마켓 심사 정책상 허용되나요? 실차 헤드유닛에서도 WebView의 WebGL을 쓸 수 있나요?
- 확인한 것: 에뮬레이터에는 Pleos 전용 WebView(Chromium 131)가 있고, WebGL2가 동작한다. 앱 화면 일부(지도)만 WebView로 그리려고 한다.
- 영향: 렌더러 A안(WebView + Pixi)과 B안(Compose) 중 무엇을 고를지(결정 6).
- 답이 없으면: B안(Compose)으로 간다. 정책 위험이 없기 때문이다.
- 답:

### A2. 주행 중 한 줄 알림을 위해 Activity에 `distractionOptimized`(DO)를 선언해도 되나요? 3rd party 앱이 DO를 선언할 때 심사 기준이 있나요?
- 확인한 것: DO를 선언하지 않으면 D 기어에서 앱이 "주행 중에는 사용할 수 없습니다"로 가려진다. 선언하면 보이고, `CarUxRestrictions`(NO_VIDEO, NO_SETUP)를 받아 직접 제한한다.
- 영향: 주행 중 시나리오 전체.
- 답이 없으면: 선언한 채로 두고, 주행 중 화면은 큰 글자 한 줄과 애니메이션 없음으로 최소화한다.
- 답:

### A3. 포그라운드 서비스(상시 알림)를 써도 되나요? 어떤 `foregroundServiceType`을 권장하나요?
- 확인한 것: 화면이 뒤로 가면 약 8초 뒤 앱이 동결된다. `dataSync` 포그라운드 서비스로는 계속 수집된다.
- 영향: 주행 중 백그라운드 신호 수집과 업로드.
- 답이 없으면: `dataSync`를 유지한다. 막히면 "앱이 화면에 있을 때만 수집"으로 줄인다(구조는 같다).
- 답:

### A4. 참가자 앱이 경고등 API(`Safety.registerTelltales`, `PRIVATE_CAR_SAFETY`)를 쓸 수 있나요?
- 확인한 것: 문서상 보호 수준이 `signature|privileged`다. 에뮬레이터에서는 부여되고 동작한다(주차 브레이크 경고등 ON/BLINK 수신).
- 영향: "내 차 트윈"의 경고등 표시.
- 답이 없으면: 있으면 보여주고, 없으면 숨긴다(이미 그렇게 구현했다).
- 답:
