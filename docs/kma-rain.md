# 기상청 강수 기반 시뮬레이터

데모에서 "가상 차 수천 대"가 실제 강수 분포대로 와이퍼를 켜게 한다. 코드는 `simulator/src/kma/`, 실행은 `simulator/src/kma-rain.ts`.

## 자료: 공공데이터포털 초단기실황 (2026-10-24 결정)

| | 초단기실황 (채택) | AWS 1분 자료 |
| --- | --- | --- |
| 서비스 | 기상청_단기예보 조회서비스 `getUltraSrtNcst` | 기상청_지상(방재, AWS) `getAws1miList` |
| 요청 주소 | `https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getUltraSrtNcst` | `https://apis.data.go.kr/1360000/Aws1miInfoService/getAws1miList` |
| 공간 | 5km 격자(nx, ny) | 지점 500여 개(좌표는 별도 엑셀) |
| 시간 | 매시 발표, "현재" | 1분, 최근 2일 |
| 승인 | 개발·운영 모두 **자동승인** | 개발·운영 모두 **심의승인** |
| 트래픽 | 개발계정 10,000건 | 개발계정 10,000건 |

- 출처: 공공데이터포털 서비스 페이지(15084084, 15057084), 2026-10-24 확인.
- 초단기실황을 고른 이유: 자동승인이라 바로 쓸 수 있고, 격자점 하나에 한 번만 부르면 된다(데모 영역 12km × 12km는 격자점 25개 = 한 시간에 25건).
- 5km 격자는 150m 격자 지도에서 너무 거칠다 → 격자점 사이를 쌍선형 보간한다.
- AWS는 필요해지면 같은 스냅숏 형식으로 붙인다(`RainSnapshot`).
- ✅ 확인(2026-10-25, 실제 호출): 응답은 `response.header.resultCode`("00" = NORMAL_SERVICE)와 `response.body.items.item[]`(`category`, `obsrValue`)이다. 한 격자점에 PTY(강수형태), REH(습도), RN1(1시간 강수량, 숫자 문자열 예 `"0"`), T1H(기온), UUU·VVV·VEC·WSD(바람)가 온다.
- ✅ 확인: **최근 1일(24시간) 자료만 준다.** 그보다 이전은 `resultCode` 10 "최근 1일 간의 자료만 제공합니다." → 비 온 날에는 하루 안에 `--backfill 24`로 한 번에 녹화한다.
- PTY(0 없음, 1 비, 2 비/눈, 3 눈 등)는 아직 쓰지 않는다. 눈을 구분할 때 쓸 수 있다.

## 인증키

- 공공데이터포털에서 사용자가 직접 발급한다(2026-10-25 발급, 개발계정, 만료 2028-10-25). 마이페이지 활용신청 상세의 "일반 인증키" 값을 `simulator/.env`에 `KMA_SERVICE_KEY=...`로 둔다. 새 화면은 키를 하나만 보여 주고, 16진수라 Encoding·Decoding 구분이 없다. `.env`는 커밋하지 않는다(`.gitignore`).
- 키는 입력을 숨기는 명령으로 넣는다(`read -rs`). 화면 캡처에 키가 보이지 않게 한다. 노출됐다고 생각되면 포털에서 재발급한다.
- 코드는 키를 환경 변수로만 읽고, 키가 들어간 URL이나 응답 원문을 로그에 남기지 않는다.

## 변환

- 위경도 ↔ 격자: 활용가이드의 람베르트 정각원추 변환식(격자 5km, 표준위도 30°·60°, 기준 126°E·38°N = 43,136). 서울 종로 → 60,127로 검증(`simulator/test/kma.test.ts`).
- 1시간 강수량 → 와이퍼 강도: 기상청 강수 강도 표현을 따른다. 0.1mm/h 미만 = 비 없음, 3 미만 = 약(1), 15 미만 = 중(2), 그 이상 = 강(3).
- 와이퍼를 켜는 차 비율: 약 75%, 중 90%, 강 97%. 켠 차의 10%는 한 단계 약하게, 10%는 한 단계 세게 둔다(서버는 중앙값을 쓴다). 같은 차·같은 격자는 매분 같은 값을 낸다.

## 가상 차

- 영역 안 아무 곳에서 출발해 조금씩 휘는 길을 약 6km 달린 차로 친다(30m 간격). 지나간 격자마다 와이퍼 켬/끔을 1분마다 올린다(`src="sim"`).
- 기본 2,500대 → 격자 약 7,900개를 지나고, k=3을 넘은 격자 약 7,800개가 배포된다(2026-10-24 로컬 확인).
- 같은 시드면 같은 무리가 나온다(`--seed`).

## 녹화와 재생 (시연 날 비가 안 와도 되게)

```bash
npm run kma -- --backfill 24           # 지난 24시간을 한 번에 녹화(비 온 날 하루 안에 한 번). 25개 격자점 × 24 = 600건
npm run kma -- --live --record-only    # 켜 두면 발표 시각마다 data/kma-YYYYMMDDHHMM.json 저장
npm run kma -- --snapshot data/kma-202611031500.json    # 녹화 재생(키 필요 없음)
npm run kma -- --live                  # 지금 강수로 업로드 + 녹화
```

- `test/fixtures/synthetic-rain.json`은 테스트·화면 확인용 **가짜 자료**다(`source: "synthetic"`). 시연에는 실제 녹화본을 쓴다.
- 녹화본은 공공데이터(기상청)다. README에 출처를 남긴다.
